# UI Implementation Skill

## Workflow
1. Inspect the existing screen and reusable components.
2. Identify the exact UI scope requested.
3. Compare the implementation with the approved v3 direction.
4. Reuse existing tokens/components where possible.
5. Implement only the requested UI change.
6. Check mobile layout, touch targets, overflow, and interaction states.
7. Run the relevant build/check.
8. Report changed files and verification.

## Guardrails
- Do not redesign unrelated screens.
- Do not invent new visual patterns.
- Do not add features under the label of polish.
- Keep Home minimal.
