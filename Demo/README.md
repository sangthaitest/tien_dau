# Tiền Đây — HTML prototype

This folder is the **only** in-repo prototype. It matches live Version C (`?v=3`).

**Not production Flutter.** Open `index.html` in a browser — no build step.

## Quick start

1. Open `index.html` (or from repo root: `Demo/`)
2. Flow: Splash → Onboarding → Login → Home
3. Add a transaction with the `+` button (amount shortcuts 10k–200k, then Chi cho)

Live preview (hosted separately): https://sangthaitest.github.io/?v=3
